# 背单词 · DSH 插件

挂在 DSH（DeepSeek Harness）Web 界面上的本地背单词浮层：一张 400×400 的小卡片，随手刷词、做四选一、测词汇量，进度全部留在本机。

## 特色

- **不打断工作**：浮层固定在迷你尺寸，可拖动；关闭后缩成一个小图标，点一下再展开。
- **三种练法**：刷词（认识 / 不认识）、四选一释义、词汇量测评，共用同一份学习记录。
- **十级记忆排期**：认识就升级，复习间隔从 5 分钟一路拉到 30 天；忘记不退级，5 分钟后重来。
- **错词不立刻重复**：答错的新词要等同一本书再答 **4 个其它新词**才重新出现，避免短时间硬记。
- **完全离线**：词库随插件分发，不联网、不上传，学习记录只写本地。
- **与桌面版同规则**：Windows 版在 [vocab-app](https://github.com/zijian-ai-projects/vocab-app) 仓库，两端学习规则一致，但资料各自独立、不同步。

## 安装

**前置**：DSH ≥ 0.2.2-rc.1，Node.js ≥ 24.9.0。

**方式一：本地包（推荐）**

1. 从 [vocab-app 的 Releases](https://github.com/zijian-ai-projects/vocab-app/releases) 下载 `dsh-vocab-app-0.1.11.tgz`；
2. 在 DSH 插件管理器里选择本地安装，选中这个 tgz；
3. 安装并启用。

**方式二：直接用本仓库目录**

把本仓库 clone 到本地，在插件管理器里把该目录作为本地插件安装（等价于 `file:` 目录依赖）。之后改了代码，重新安装一次生效。

安装完成后**刷新已登录的 DSH 页面一次**即可，不需要重启服务，也不影响 Windows 版程序。

## 使用

首次进入先选词书：点进分类 → 选到最细一级 → 确认「用这本开始」。没有默认词书，也不会悄悄替你选。

| 场景 | 按键 |
|---|---|
| 刷词 · 正面 | `Enter` 认识；`空格` 不认识 |
| 刷词 · 背面 | `空格` 把刚才的「认识」改判为不认识；`Enter` 进入下一词 |
| 四选一 | `1`–`4` 选释义；`空格` 不认识；答完用 `空格` / `Enter` 下一个 |
| 词汇量测评 | `1`–`4` 选释义；第五行「不认识」按 `空格` |

窗口固定 400×400，不支持拖边改大小；标题栏可拖动。关闭后浮动图标可拖动，位置只保留在当前会话内。

## 学习规则

| 等级 | 复习间隔 |
| --- | --- |
| 0 | 新词，尚未认识，暂无排期 |
| 1 | 5 分钟 |
| 2 | 30 分钟 |
| 3 | 12 小时 |
| 4 | 1 天 |
| 5 | 2 天 |
| 6 | 4 天 |
| 7 | 7 天 |
| 8 | 15 天 |
| 9 | 30 天 |
| 10 | 已掌握，不再进入常规队列 |

- 认识新词进入 1 级；之后记得就升一级，按新等级排期。
- **忘记不退级**：1–9 级旧词从这次「不认识」起 5 分钟后再到期；再答错仍重新等 5 分钟。
- 到期旧词优先于新词；同一队列只取当前选中的那本书。
- 没有每日目标、打卡门槛或活动记账——想做多少做多少。

## 数据与隐私

- 记录保存在 DSH 资料命名空间 `dsh-vocab-app/vocab_app_default`，写在插件目录的 `data/` 下。
- 升级插件不会清空学习状态、词书游标、测评历史或暂停中的测试。
- 保存采用原子写入并保留上一份有效备份；文件损坏时优先恢复，而不是当成空进度覆盖。
- 全程不联网，不上传学习记录。

## 许可与限制

- 仓库为私有发行渠道，`package.json` 标记 `private: true` / `UNLICENSED`，未发布到 npm。
- 词汇量测评的题目难度与区分度为固定参数、**未经实测标定**，结果区间只反映当前模型假设，不等同 CEFR、VST 词族数或考试分数。
- 更细的界面行为、测评方法与参考来源见 [0.1.11 技术说明](docs/notes-0.1.11.md)。
